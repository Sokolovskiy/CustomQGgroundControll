# Herelink GCS для Windows

Herelink GCS — збірка QGroundControl 5.1.5 для Windows x64 із відео RTSP, телеметрією MAVLink та екраном OSD. Нижче описано комплект із двома Herelink у режимі AirUnit-to-AirUnit і пультом RadioMaster TX16S через USB.

## Встановлення

1. Завантажте `HerelinkGCS-*-windows-x64-setup.exe` зі сторінки [Releases](https://github.com/Sokolovskiy/CustomQGgroundControll/releases). Файл `SHA256SUMS.txt` містить контрольну суму інсталятора.
2. Запустіть інсталятор і відкрийте **HerelinkGCS** у меню **Пуск**. Інсталятор містить Qt, GStreamer та бібліотеки Visual C++. Для роботи з бортом підготуйте мережу Herelink і відкалібруйте свій пульт.
3. Якщо Windows запитає доступ до мережі, дозвольте його для довіреної приватної мережі Herelink.

## Налаштування TCP/IPv4 у Windows

Ці параметри потрібні для прямого Ethernet-з’єднання ПК із GroundUnit у схемі AirUnit-to-AirUnit. Виконайте ці кроки перед налаштуванням UDP і відео в Herelink GCS.

1. Підключіть ПК кабелем Ethernet до GroundUnit. На час першого підключення вимкніть Wi-Fi.
2. Натисніть **Win + R**, введіть `ncpa.cpl` і натисніть **Enter**. Клацніть правою кнопкою адаптер **Ethernet**, до якого під’єднано GroundUnit, і відкрийте **Властивості**.
3. Виберіть **Протокол Інтернету версії 4 (TCP/IPv4) → Властивості → Використовувати таку IP-адресу**.
4. Введіть IP-адресу ПК `192.168.144.3` і маску підмережі `255.255.255.0`. Для цього з’єднання залиште поля основного шлюзу й DNS порожніми. Натисніть **OK**. [CubePilot, розділ 4. PC setup](https://docs.cubepilot.org/herelink/herelink-user-guides/herelink-1.0-airunit-to-airunit-instruction#id-4.-pc-setup)

## Перше підключення

Виконайте налаштування на стенді зі знятими пропелерами та в стані **DISARMED**. Спочатку перевірте мережу, потім телеметрію, відео й органи керування.

1. Після налаштування Ethernet увімкніть борт. Закрийте інші наземні станції, які використовують той самий UDP-порт.
2. Відкрийте **Application Settings → Comm Links → Add** і створіть з’єднання типу **UDP**. Для перевіреної схеми введіть **Port** `14552` та через **Add Server** додайте `192.168.144.11:14552`. Збережіть, виберіть з’єднання і натисніть **Connect**. Якщо у вашій схемі інші адреси або порти, використовуйте значення зі своєї конфігурації Herelink.
3. Дочекайтеся, поки в **Fly View** з’явиться борт і завантажаться його параметри.
4. У **Application Settings → Video** виберіть **RTSP Video Stream**. Для цієї схеми URL — `rtsp://192.168.144.10:8554/H264Video`. Для перевірки на стенді вимкніть **Disabled When Disarmed**, якщо цей пункт увімкнено. Переконайтеся, що зображення оновлюється.

## TX16S як USB-джойстик

1. На TX16S виберіть потрібну модель. Під’єднайте його кабелем USB із підтримкою даних і виберіть режим **USB Joystick**.
2. З під’єднаним бортом відкрийте **Vehicle Setup → Joystick**. Виберіть TX16S, запустіть **Calibrate** і пройдіть кроки калібрування. Перевірте напрямки, центри та крайні положення всіх осей.
3. На вкладці **Buttons** перемикайте органи керування по одному й дивіться, який номер бачить програма. Для наявного профілю ПК налаштування були такими. На іншому пульті номери можуть відрізнятися.

   | Індекс кнопки | Дія |
   | --- | --- |
   | 2 | Altitude Hold |
   | 3 | Position Hold |
   | 4 | Land |
   | 5 | Camera Relay OFF |
   | 6 | Camera Relay ON |

   Залиште повтори кнопок вимкненими. ARM і DISARM у цій схемі виконуються вручну з панелі стану в **Fly View**.
4. Якщо борт підтримує цю схему нахилу камери, перевірте вісь, відкалібруйте її та зіставте з **Additional Axis 6** в режимі **RC Override**. Наявний профіль використовує USB-вісь з індексом 4, а GCS передає команду як RC10. На стенді звірте напрямок і крайні положення з рухом камери. OSD показує заданий кут.

USB-калібрування та призначення кнопок зберігаються в Herelink GCS на конкретному ПК. Профіль EdgeTX зберігає мікси й налаштування на пульті. Для ручного Herelink через SBUS використовуйте налаштування конкретного борту.

## Fly View та камери

- **F11** перемикає повноекранний режим. Поточний режим польоту показано вгорі ліворуч. Список режимів містить Altitude Hold, Position Hold, Land і RTL, якщо їх пропонує автопілот.
- **Verba** використовує Relay2. Залиште **Herelink HDMI** вимкненим. **Camera Relay OFF** вибирає **CAM1 MAIN**, а **ON** — **CAM2 STAB**.
- **Scorpion** використовує входи AirUnit HDMI 1 і HDMI 2. У стані **DISARMED** клацніть правою кнопкою **OSD** і ввімкніть **Herelink HDMI** для цього борту. Ті самі кнопки вибиратимуть HDMI 1 і HDMI 2. Позначка `?` означає, що вибір ще очікує підтвердження. Перевірте обидва переходи за зображенням.
- Напруга на комірку в OSD обчислюється для **12S**. Використовуйте це показання лише для відповідної батареї.

Перед польотом перевірте реакцію борту на осі та перемикачі, зображення з обох камер, передпольотні попередження й налаштовану реакцію на втрату зв’язку. Якщо контролер відхиляє ARM, відкрийте повідомлення в **Fly View** і усуньте причину. [Передпольотні перевірки ArduCopter](https://ardupilot.org/copter/docs/common-prearm-safety-checks.html)

## Як додати модель HERELINK на TX16S

1. Під’єднайте ввімкнений TX16S через USB, виберіть **USB Storage** і відкрийте папку `MODELS` на диску пульта.
2. Перейменуйте копію `TX16S/HERELINK.yml` з архіву на `modelXXX.yml`, де `XXX` — наступний вільний номер після найбільшого на пульті. Якщо найбільший номер має `model11.yml`, назвіть нову копію `model12.yml`.
3. Скопіюйте перейменований файл у `MODELS`. Збережіть наявні файли моделей.
4. Безпечно витягніть диск, від’єднайте USB і виберіть **HERELINK** у списку моделей на пульті. Перевірте осі та перемикачі на стенді. Для підключення до GCS виберіть режим **USB Joystick**.

Для резервної копії перенесіть файл моделі з `MODELS` у папку на ПК. Назву моделі можна звірити в полі `header → name` у файлі YAML. [Посібник EdgeTX](https://github.com/EdgeTX/edgetx-user-manual/blob/2.12/color-radios/select-model.md)

## Якщо щось не підключається

| Симптом | Що перевірити |
| --- | --- |
| **NO VEHICLE** | З’єднання Herelink, IP і UDP-порт, кнопку **Connect**, правила Windows Firewall і чи вільний порт. |
| Є телеметрія, але немає відео | URL RTSP, живлення й HDMI-вихід камери, вибір входу на AirUnit та **Disabled When Disarmed**. |
| TX16S не видно | Режим **USB Joystick**, кабель і вкладку **Joystick**. |
| Камера не перемикається | Вибір профілю Relay2 або HDMI, призначення кнопок і зміну картинки на стенді. |
